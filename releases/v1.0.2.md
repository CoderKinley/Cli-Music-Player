# Musik v1.0.2

This patch fixes how the installed `musik` command starts the application.

## Fixed

- Running `musik` now keeps Musik attached to the terminal that invoked it.
- The installer no longer routes terminal launches through Velopack's detached launcher.
- Updating from v1.0.0 automatically replaces the old PATH entry with the direct console executable path.
- Uninstall cleanup removes both the current and legacy PATH entries.

## Installation

Download and run `Musik-Setup.exe`. Existing installations can run:

```powershell
musik update
```

Open a new terminal after installation or updating so it receives the refreshed user PATH.

## Windows notice

The installer is not currently code-signed. Windows SmartScreen may display an
unknown-publisher warning; verify the checksum in `SHA256SUMS.txt` if desired.
