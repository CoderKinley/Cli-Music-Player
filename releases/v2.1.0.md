# Musik v2.1.0

Musik 2.1 improves browsing responsiveness with silence trimming enabled and
refines the live spectrum visuals.

## Highlights

- Tail-silence analysis runs only for the playing song. Highlighting songs and
  preparing the next queue entry no longer launch additional tail-scan decoders.
- Obsolete silence scans are cancelled, including their child downloader
  processes, before another scan starts. Scans run in the background with
  caching and read-ahead disabled.
- Playlist, favorites, and dashboard navigation repaint only changed highlight
  rows when the visible page stays the same. Batched terminal output and less
  text allocation reduce drawing overhead.
- Cat Halo keeps mirrored, music-reactive head and ear outlines, with spectrum
  strokes extending outward from the ear edges and bass near the ear tips.
- Denser, continuous spectrum outlines improve visibility across panel sizes,
  and the visualizer respects the terminal's default background.

## Validation

- Regression checks cover incremental navigation, scrolling and wrapping,
  Unicode text, terminal colors, spectrum bounds, and mirrored geometry.
- Real mpv/WASAPI checks verify that preloading starts no tail-silence scans,
  while leading/trailing trimming, internal pauses, crossfades, seeking, and
  disabled-trimming behavior continue to work.

## Updating

Existing installed copies can update after this release is published:

```powershell
musik update
```

For a new installation, download `Musik-Setup.exe`. A portable ZIP and SHA-256
checksums are also included with the release.

## Windows notice

The installer is not currently code-signed. Windows SmartScreen may show an
unknown-publisher warning.
