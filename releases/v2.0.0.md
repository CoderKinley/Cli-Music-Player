# Musik v2.0.0

Musik 2.0 brings live audio visualizations and smoother transitions to the
Windows terminal player.

## Highlights

- Choose Cat Outline, Cat Halo, Aurora Bars, Aurora Wave, Orbit, Silk Wave, or
  Off from the new Spectrum & Transitions screen. The preview responds to the
  playing track.
- Live frequency analysis follows Musik's audio process, so the display tracks
  the sound you hear and returns to silence when playback stops or pauses.
- The queue prepares the next track in the background. Manual track changes
  start the new track promptly while fading out the previous one; automatic
  changes use overlapping fades.
- Set crossfade length to Off, 1.5, 3, or 5 seconds and optionally trim quiet
  track edges. These preferences persist between launches.
- Aurora Wave mirrors its spectrum above and below the centerline. Cat Halo
  draws audio strokes from the outer edge of the face and ears.

## Reliability

- Regression checks cover frequency placement, visualizer geometry, pause and
  seek behavior, preloading, crossfades, and playlist navigation.

## Updating

Existing installed copies can update with:

```powershell
musik update
```

New users can download and run `Musik-Setup.exe` from this release. The
portable ZIP is also available.

## Windows notice

The installer is not currently code-signed. Windows SmartScreen may show an
unknown-publisher warning. SHA-256 checksums are included with the release.
