# Musik v1.4.0

This release keeps song and artist names within the terminal layout, reduces
input flicker, and adds removal of individual songs from saved playlists.

## Highlights

- Song titles and artist names share one terminal-width limit, with room
  reserved for the artist and ellipses for long names.
- Japanese text, emoji, and combining characters are clipped without splitting
  characters or spilling across panel borders.
- Search and playlist input fields redraw only when their text or window size
  changes, with the caret hidden during repainting to prevent jumping.
- Long search queries and playlist names scroll within the input field.
- Inside a saved playlist, Delete or Backspace removes the selected song and
  saves the change immediately. Favorites and other playlists are preserved.
- Playback queues skip removed songs, and playlists remain safe to navigate
  after removing their final song.

## Reliability

- Added regression checks for terminal layout, playlist persistence, and queue
  navigation, and run them before packaging each release.
- Includes the YouTube playback and download improvements from v1.3.0.

## Updating

Existing installed copies can update with:

```powershell
musik update
```

New users can download and run `Musik-Setup.exe` from this release.

## Windows notice

The installer is not currently code-signed. Windows SmartScreen may show an
unknown-publisher warning. SHA-256 checksums are included with the release.
