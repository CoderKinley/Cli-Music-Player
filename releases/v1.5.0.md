# Musik v1.5.0

This release adds a searchable keyboard guide, makes navigation easier, and fixes
playback-panel flicker and low-contrast text in the Spotify and SoundCloud themes.

## Highlights

- Open the keyboard guide from Home or with F1. Browse categories or search by
  shortcut and keyword; return to your previous screen without losing typed text.
- Press I on Home or in a song list to read the full song title, artist, duration,
  and source in a scrollable details page.
- Navigate longer lists with Page Up, Page Down, Home, and End. Song lists show
  the visible range and total count.
- The playback panel updates only changed text and progress cells instead of
  repainting four times a second. Pausing, seeking, resizing, and returning from
  other screens refresh the relevant parts correctly.
- Spotify and SoundCloud themes use white labels and brighter gray instructions
  for readable menus, song lists, and help text.
- Improved layouts keep the player, status messages, and keyboard hints separate
  in smaller terminals. Windows emoji widths are accounted for to protect borders.
- Search accepts Q as text, preserves queries when opening help, and supports
  starting another query with / from results.
- Includes a complete keyboard and usage guide in the README and release packages.

## Validation

- 8,112 regression checks cover terminal text, playback rendering, theme colors,
  playlist persistence, and playback queues.
- Live terminal checks cover idle rendering, guide navigation, song selection,
  favorites, and theme switching.

## Updating

Existing installed copies can update with:

```powershell
musik update
```

Download `Musik-Setup.exe` for a new installation, or use the portable ZIP.
SHA-256 checksums are included in `SHA256SUMS.txt`.

WinGet users can install with:

```powershell
winget install --id CoderKinley.Musik --exact --source winget
```

Then run `musik update` if the catalog still lists an older version.
