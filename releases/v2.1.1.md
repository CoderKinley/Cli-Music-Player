# Musik v2.1.1

Fixes forced black backgrounds throughout the terminal UI.

- Menus, playlists, favorites, playback text, and empty progress cells now use
  the terminal's default background, matching the spectrum.
- Colored selection highlights and filled progress indicators are preserved.
- Regression checks cover default-background restoration, colored fills,
  terminal colors, clipping, and batched rendering.

## Updating

```powershell
musik update
```

For a new installation, download `Musik-Setup.exe`. A portable ZIP and SHA-256
checksums are also available.
